# Azer Engine

My scrapped Friday Night Funkin' Psych Engine fork.

I started this project to add some things that I thought Psych Engine lacked, but clearly, I did not make it very far.

## Planned Features

- Modular chart editor supporting more than two lane groups
  and multiple characters.
- Potential image editor integrated into the character editor.
- More intuitive stage editor.
- Potential menu editor.

## Status

I have stopped working on this project as I found that it would not be of much use. If you would like to fork this and edit stuff, or continue where I left off, feel free! I may return to this project, but it's unlikely.
